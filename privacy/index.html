Политика конфиденциальности

Редакция от 7 октября 2026 года

Эта политика относится к ZMA Content — сервису команды ZMA-Авто для подготовки и публикации материалов в собственных или явно подключённых владельцем аккаунтах социальных платформ, включая Instagram и Threads. Ответственный за приложение: Никита Зверев. Политика сайта по подбору автомобилей является отдельным документом.

1. Какие данные используются

  • Идентификатор подключённого аккаунта, имя пользователя и доступные через разрешённый API сведения о профиле.
  • Токен доступа и сведения о выданных разрешениях, необходимые для подключения к платформе.
  • Фотографии, видео, подписи, ссылки и задания на публикацию, которые владелец предоставляет или согласовывает для выпуска.
  • Идентификаторы и ссылки опубликованных материалов, время и результат операций, технические ошибки. Доступные показатели публикаций используются только при наличии соответствующего разрешения.
  • Сведения, добровольно переданные при обращении по вопросам подключения или удаления данных.

Приложение не запрашивает пароль Instagram через собственную форму. Доступ к Instagram выдаётся на странице платформы. Наличие разрешения в конфигурации Meta само по себе не означает доступ к данным аккаунта. На дату этой редакции переписка Instagram Direct не обрабатывается; подключение такой функции потребует отдельного информирования и разрешения владельца.

2. Для чего нужны данные

Для проверки принадлежности и доступности аккаунта, подготовки согласованных публикаций, передачи материалов в API выбранной платформы, проверки результата и предотвращения повторных публикаций после ошибки. Формат выпуска, включая Reels, Trial Reels или Stories, зависит от доступности API, прав аккаунта и согласованного задания.

3. Основания и передача

Подключение выполняется по поручению владельца аккаунта и в пределах предоставленных им разрешений. При публикации согласованный материал передаётся выбранной социальной платформе. Инфраструктура хостинга обрабатывает данные для работы сервиса. Мы не продаём данные и не передаём их для самостоятельной рекламы третьих лиц. Передача также возможна, когда она требуется применимым законодательством.

Платформа самостоятельно обрабатывает полученные материалы по своим правилам. Публичность постов определяется выбранным форматом и настройками аккаунта. Приложение не использует данные аккаунта для создания CRM-переписки с клиентами.

4. Хранение и защита

Секреты подключения хранятся отдельно от исходного кода и публичных документов. Доступ к рабочему кабинету ограничен авторизацией. Для передачи по API и доступа к кабинету используется HTTPS. Токены не публикуются в открытых страницах и журнале состояния.

Данные хранятся в течение срока, необходимого для работы подключённого аккаунта, проверки выпуска и исключения дублей. При отключении или подтверждённом запросе на удаление прекращается дальнейшее использование подключения и удаляются относящиеся к нему токены и данные в управляемых хранилищах. Отдельные записи могут сохраняться только при наличии обязательного правового основания; о таком исключении сообщается заявителю.

5. Cookie и технические данные

Рабочий кабинет использует cookie сессии для авторизации. Серверы могут обрабатывать IP-адрес и параметры HTTP-запросов для доставки страниц и защиты сервиса. Эти страницы документов не содержат рекламных трекеров, форм сбора данных и сторонней аналитики.

6. Права и удаление

Владелец может отозвать доступ на стороне платформы, запросить сведения об обработке, исправление или удаление данных. Пошаговый порядок опубликован на странице «Удаление данных». Отзыв разрешения и удаление данных из ZMA Content не удаляют автоматически посты из социальной платформы.

7. Связь и изменения

Обращения принимаются по контакту внизу страницы. Для защиты аккаунта может потребоваться подтверждение владения; пароль и токен в обращении не нужны. Актуальная редакция публикуется по этому адресу. Изменение целей или состава доступа требует обновления политики и соответствующих разрешений.
